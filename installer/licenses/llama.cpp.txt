llama.cpp, the program that runs local models for Perplexify
=============================================================

Perplexify ships the unmodified release build b12359 of llama.cpp (the Windows Vulkan build from
https://github.com/ggml-org/llama.cpp/releases) in the folder `llama` next to the app. The build is used as it is.
Its source code is at https://github.com/ggml-org/llama.cpp (tag b12359).

llama-server and the ggml libraries are licensed under the MIT License (first text below). The same release also
contains code of other projects: cpp-httplib and JSON for Modern C++ (MIT, texts below); stb_image.h, subprocess.h and
miniaudio (each in the public domain, or under the MIT licence, at your choice); the Khronos Vulkan headers that
ggml-vulkan.dll was built with (Apache-2.0 or MIT); and the LLVM OpenMP runtime (libomp.dll), whose licence is the
file LICENSE-LLVM-OpenMP in this folder (Apache License v2.0 with LLVM Exceptions).
The Vulkan driver itself comes with the graphics card driver of your computer and is not part of Perplexify.
